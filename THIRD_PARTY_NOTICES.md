# Third-party notices

Reviewed: 2026-09-22

This file identifies third-party material represented in the source dependency
graph. It does not replace the complete license texts distributed by upstream
projects or the machine-readable release SBOM. Versions are pinned by `go.mod`
and `go.sum`.

## Embedded Forecast Ledger contract

The embedded Forecast Ledger v2.0.1 schema, examples, conformance fixtures, v2
seal and target vectors, and required v2 reference documents were copied
from <https://github.com/chaoscondensate/schema> at commit
`55b1431d379128e1d75b9c30a3874398cea9ff0f` and retain the upstream MIT
license. Exact file digests, provenance, and license text are stored in
[`third_party/forecast-ledger`](third_party/forecast-ledger/).

## OpenSpec agent skills

The repository-local OpenSpec agent skill instructions under `.agents/skills`
were generated by OpenSpec and declare the MIT license. They are development
inputs and are not included in Forecast Ledger CLI release archives.

## Embedded FreeTSA trust material

The built-in RFC 3161 profile embeds the public FreeTSA root certificate bytes
retrieved from <https://freetsa.org/files/cacert.pem> on 2026-08-30. The exact
source-file SHA-256, certificate identity, validity, qualification limits, and
rotation procedure are recorded in
[`docs/development/rfc3161-providers.md`](docs/development/rfc3161-providers.md).
Embedding a public certificate records a trust choice; it is not an endorsement
or service-availability claim.

Organization for Ethical Source. The upstream work and the project adaptation
are licensed under CC BY-SA 4.0; attribution and the permanent source link are
included in that file.

## Maintenance rule

After a module or vendored-material update:

1. verify the upstream license files from the resolved source;
2. update this inventory and any retained notices;
3. run the project's licensing compliance check; and
4. inspect the generated release SBOM before publication.

# Forecast Ledger v2.0.0

v2.0.0 is the first contract designed for lossless platform interchange and
reproducible scoring as well as direct human-authored ledgers.

## Highlights

- immutable, append-only question revisions;
- explicit outcome space, domain, and forecast representation layers;
- exact decimal-string probabilities;
- versioned options and bins;
- PMF, binned PMF, quantile, CDF, point, and credible-interval representations;
- explicit tails and interpolation semantics;
- categorical, ordinal, numeric, date, and datetime domains;
- typed resolution with ambiguous, void, disputed, and not-applicable outcomes;
- optional provenance, lifecycle events, groups, and conditional relationships;
- `forecast-seal/v2` and `forecast-envelope/v2` binding the full revision;
- frozen v1.3.0 byte verification in continuous integration.

## Compatibility

This is an intentionally breaking release. The decision and migration guidance
are recorded in [v1 to v2 compatibility](../compatibility-v1-v2.md). v1.3.0
bytes and tag remain unchanged.

## Conformance evidence

The repository contains:

- valid JSON and YAML examples;
- positive conformance fixtures for relationships, ordinal outcomes, datetime,
  and `not_applicable`;
- mutation-based invalid cases for arithmetic, versions, bins, monotonicity,
  references, cycles, lifecycle, resolution, timestamp chronology, and reveals;
- deterministic v1 and v2 seal vectors;
- a legacy digest manifest for the v1.3.0 schema and vector.

The annotated `v2.0.0` tag identifies the exact release commit. GitHub Release
assets contain the complete source archive and `SHA256SUMS`; the release job
builds both only after all conformance checks pass.
